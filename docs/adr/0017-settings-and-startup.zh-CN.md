# ADR-0017：全局设置与登录自启

[English](0017-settings-and-startup.md)

相关：[ARCHITECTURE §10.1、§11](../ARCHITECTURE.zh-CN.md)；[ADR：不卡键](0006-no-stuck-keys.zh-CN.md)；[ADR：进程与技术栈](0001-processes-and-stack.zh-CN.md)

## 背景

- `timing` 和 `safety.panic` 原来只在启动时读，改了没反应，界面显示的值与运行中的不一致。紧急组合在 T-input 上检测，只在设备连上时选一次。
- 登录自启写在 HKCU 的 Run 里，命令行不能超过 260 个字符。绝对路径的 exe、profile 和日志路径拼起来可能到 360。注册表不校验，写成功不能证明下次登录能启动。
- 开发版界面的 daemon 有自己的实例名和管道，托盘仍显示“登录时启动”，点一下就会用开发版覆盖用户真实的自启值。

## 决定

### 一、全局设置保存即生效
- **时序。** `config.put` 提交后，daemon 用新的全局值重新编译正在运行的配置。四个时间没变就不动，变了走保存配置时的重载：松开按着的键，重建脚本，层状态和 session 保留。
- **紧急组合。** `safety.panic` 变了，daemon 在 T-input 上按每个设备记下的信息重新选组合，清掉已按下的成员和计时。新组合要所有成员重新按下才触发，正在按住的旧组合不会触发。检测仍在 T-input 上、事件进通道之前。
- 组合至少 2 个键、按住至少 500 ms，否则校验失败，稍长按一个键就不会误触发紧急暂停。组合按设备族生效，缺键的手柄沿用默认组合，不会没有紧急暂停。生效的组合由 daemon 算出，经 `status.get` 返回，界面不再自己选。
- 在手柄上录新组合时，界面经 `capture.start` 暂停映射，按键不会触发快捷键。捕获归 bridge 连接，窗口失焦、关闭、断连等一切异常都要结束捕获。录入时按住旧组合仍会切换暂停，作为安全出口。
- 忽略的设备和 `restoreLayerState` 仍要重启才生效。反馈开关即时生效（[手柄反馈](0015-controller-feedback.zh-CN.md)）。
- config.json 只有 `config.put` 一条提交路径，界面是唯一的写入者。

### 二、登录自启
- **开关归守护进程。** 托盘菜单和 `startup.get`、`startup.set` 都经同一个自启项，用互斥锁串行。客户端不能传 exe 或参数：命令总是守护进程自己的可执行文件和启动参数，否则任何认证过的客户端都能让 padmate 登录时以任意参数启动。
- 只有明确点击托盘或设置页的开关才写 HKCU Run。
- **开发版和测试构建不写自启**：`startup.get` 报不可用，`startup.set` 返回 -32017，托盘灰显。这些构建只用内存里的自启项，每次读写前再查一次。
- **长命令用参数文件引用。** 命令超过 260 个 UTF-16 单元时，把完整参数写进 `%APPDATA%\padmate\startup\<id>.json`，Run 里只写 `padmated.exe --startup-id=<SHA256>`。文件不可变，以内容哈希为名，写完才写 Run；写 Run 失败只移除本次新建的文件。`--startup-id` 入口只接受独占的 argv，校验摘要、版本和 exe 路径，任何一项不对都失败退出，不回退为注入，不用默认 profile。超长到引用也放不下就明确失败，不改动已有的 Run。
- GUI 登录启动可以没有 stdout，演练 printer 写 `io.Discard`，模式仍是 dry-run。`--log-file -` 回退默认持久日志。
- 打包版界面用 `--inject` 启动守护进程，所以登记的自启也是 `--inject`；开发版、E2E 和测试仍用 `--dry-run`。

## 代价

- 改时序会松开正在按着的键、重建脚本，和保存配置一样。这时前台通常是 padmate 窗口，不发键。
- 已有 config.json 里 1 个键或短于 500 ms 的组合从此校验失败，按坏文件处理（自动修复）。
- 参数文件不会因取消自启而清理，用户删掉被引用的文件会导致下次启动失败，重新启用可以重建。
- 移动 exe 或 profile 后要重新启用自启。摘要只是完整性校验，不是对同用户的安全隔离。
- 真实的注销和登录只能手动验收。

## 放弃的做法

- **改设置后重启生效，或只改全局值不重载运行中的配置。** 用户试不出效果。
- **`Repick` 保留已按下的成员。** 按住的旧组合可能在换完后立刻触发。
- **对话框里用下拉框选按钮。** 用户得知道按钮在 SDL 里的名字。
- **开发版也能写自启，只提示风险。** 用户的真实自启会被换成开发版的演练模式。
- **自启项只在托盘里建。** 设置页和托盘可能同时写，状态分两份。
- **截断参数。** 会掩盖缺陷。
- **组合的下限只放在界面录入里。** 手改 config.json 仍能写 1 个键，daemon 也照用。
- **打包版界面用 `--dry-run`，自启时改登记 `--inject`。** 用户试的和登录后用的不是一回事。
