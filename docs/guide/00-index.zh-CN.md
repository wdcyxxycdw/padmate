# padmate 使用指南

[English](00-index.md)

padmate 把手柄上的按键、摇杆和扳机变成键盘快捷键。典型用法是画画时左手握手柄、右手握笔。

引号里的字是中文界面上的原文。界面语言默认是安装时选的那种；要改，打开“设置”，在“通用”里改“语言”。

3. [层和功能键](03-layers-and-function-keys.zh-CN.md)：让同一个键在不同时候做不同的事。
