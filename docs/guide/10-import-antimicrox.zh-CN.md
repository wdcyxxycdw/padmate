# 导入 AntiMicroX

[English](10-import-antimicrox.md)

AntiMicroX 是另一个把手柄变成键盘的程序。它的配置文件可以读进 padmate，不用重做。

## 导入

1. 左边点“配置”，点页面顶部的“导入…”。
2. 选 AntiMicroX 的配置文件，扩展名是 `.amgp`（旧版本是 `.xml`）。
3. padmate 新建一个配置，并弹出一份导入报告。

也可以用命令行：在 `resources\bin` 文件夹里运行 `.\padmatectl.exe profile import-amgp 文件`。

只收游戏手柄的配置，文件最大 1 MiB。很旧的文件（`configversion` 小于 6）会被拒绝，可先用较新的 AntiMicroX 打开并另存，再试。

## 看报告

报告按严重程度分三组，每行写着它在文件里的位置和原因：

- “丢弃”：这一项没有导入。
- “近似”：padmate 有接近的做法，但行为略有不同。
- “信息”：一条说明，有时提醒你检查。

点“打开配置”打开新配置。按 Esc 或点关闭按钮只关报告，新配置仍在配置页的列表里。报告里的原因只有中文。

## 会变样的

- 摇杆、扳机和十字键的设置：AntiMicroX 里每个 set 各有一份，padmate 里整个配置只有一份。导入用 set 1 的，其他 set 里不同的列在报告里。
- set 1 里按住 View 或 Menu 来换 set 的设置，导入为功能键的一套按键。功能键默认是 Menu，所以 Menu 上的绑定默认不生效，报告会说明。功能键在 padmate 的设置里选。
- 一个 set 导入为一层。界面只编辑 base 层，其他层只能在文件里改，见[层和功能键](03-layers-and-function-keys.zh-CN.md)。按住换 set 的那一层里，没有绑定的键会被屏蔽，因为 AntiMicroX 的 set 是整套替换。
- 每按一次循环到下一段动作的设置，导入为双击到四击，条件是复位时间不超过 1000 毫秒，否则只保留第一段。界面只显示“点按”“长按”和“双击”，三击和四击照常生效，只能在配置文件里改。有双击时，单击的动作要等到确定没有第二下才触发。
- 键码按美式键盘导入。需要 Shift 的字符，例如 `!`，写成 `Shift+1`。小键盘的导航键按数字键导入，要开着 NumLock 才对得上。F25 以上、浏览器键、启动键这类没有对应键的被丢弃。

## 导入后检查什么

1. 看一遍报告里的“丢弃”和“近似”。
2. 在“映射”页看一遍每个键，确认快捷键对。
3. 用手柄试几个键，尤其是长按和双击。
