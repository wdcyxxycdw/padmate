# 配置和按软件切换

[English](06-profiles.md)

一个配置是一整套按键设置。可以给每个软件一个配置，padmate 跟着前台软件自动换。

## 配置页

左边点“配置”，打开配置页。

- 最上面是“默认”配置，写着“未绑定的软件使用此配置”。它不能删除，也不能改名，但可以改键。
- padmate 自带一份给 CLIP STUDIO PAINT 用的配置 CSP，已经绑定这个软件。它在 padmate 启动时加进来，只加一次，你已有同名配置时不加；删掉它或它的绑定以后不会再出现。
- 其余每个配置一张卡片，用图标列出它用于哪些软件。正在使用的带着“使用中”。
- 点铅笔按钮“编辑按键”，在“映射”页编辑这个配置。点“复制”得到同样的配置，改它不影响原配置，但它没有绑定软件。
- 卡片的菜单里有“导出…”“配置设置…”“重命名…”和“删除…”。页面顶部有“导入…”和“新建配置”。
- 配置文件有错误的卡片会写着“配置文件有错误”，不能打开。

“新建配置”只要写“名称”再点“新建”，就得到空配置，名称不能与别的配置重名。“删除…”删除整个配置，包括它的脚本，不能恢复。

## 按软件自动切换

页面顶部的“按软件自动切换配置”默认开着。开着时，padmate 按前台软件换成绑定它的配置，没有绑定的软件用“默认”配置。

- 在配置卡片上点“添加软件”，有三种选法：“点选窗口…”（要在 30 秒内点到目标窗口）“从已安装的软件中选择…”和“浏览…”。
- 软件按程序文件名认，不看窗口标题。同名的不同程序用同一个配置。
- 点卡片上的软件图标，菜单里有“停用”（以后再点是“启用”）和“解除绑定”。“停用”让绑定暂时失效但保留。
- 一个软件只能绑定在一个配置上。已绑定在别处时，会问“保留”还是“更改”。
- 以管理员身份运行的软件也能绑定，但 Windows 可能拦下发给它的快捷键。

## 导入和导出

- “导出…”把一个配置存成 `.padmate` 文件，配置用到的脚本也在里面。
- “导入…”读这样的文件，一个文件一个配置，最大 4 MiB。AntiMicroX 的配置文件也用它导入，见[导入 AntiMicroX](10-import-antimicrox.zh-CN.md)。
- 已有同名配置时会问怎么办：“替换”覆盖那个配置的全部内容，“另存为”用新名字另存。
- 导入的脚本会直接运行，只导入信得过的文件。
