# 常见问题

[English](14-faq.md)

## Windows 提示“Windows 已保护你的电脑”

这是 Windows SmartScreen。安装程序没有代码签名，每个新版本都要从零积累信誉，所以出现这个提示。点“更多信息”，再点“仍要运行”。

要确认下载的文件没被改过，可对 SHA-256。安装程序旁有同名、末尾加 `.sha256` 的文件，地址是 `https://padmate.download/` 加安装程序的文件名再加 `.sha256`，在浏览器里打开就能看到值。在安装程序所在的文件夹打开 PowerShell，运行 `Get-FileHash .\安装程序.exe -Algorithm SHA256`，文件名换成你下载的那个。比较不分大小写，两个值一样，文件就没被改过。

## 杀毒软件拦下了 padmate，或者报毒

没有签名的程序更容易被个别杀毒软件拦下。padmate 有这两件事可能被当成可疑行为：

- 用 Windows 的 SendInput 发送快捷键，这是它的本职。
- 只在你点“录入快捷键”时才装键盘钩子，最长 30 秒。钩子只看按了什么键，不改不拦。

被隔离时这样恢复：

1. 打开“Windows 安全中心”，进“病毒和威胁防护”，点“保护历史记录”。
2. 找到被拦下的 padmate 文件，选择允许或还原。
3. 若仍被拦，只把 `padmated.exe` 和 `padmatectl.exe` 这两个文件加入排除项。它们在安装目录的 `resources\bin` 文件夹里。

不要把整个安装文件夹排除，也不要为此关掉杀毒软件。认为是误报的话，请到 padmate 的 [GitHub 页面](https://github.com/wdcyxxycdw/padmate/issues)提交 issue，写明杀毒软件的名称和版本、被拦下的文件和 padmate 的版本。

## 按了手柄，什么也没发生

1. 窗口顶部的状态应是“运行中”。是“已暂停”则点“恢复映射”。
2. 目标软件要在前台。padmate 自己的窗口在前台时不发快捷键。
3. 这个键在“映射”页不是“未设置”，左上角的配置是你以为的那个。
4. 目标软件以管理员身份运行时，请用普通权限重启它。
5. 打开诊断页，按这个键，看新的一行。有行则结果一栏说明原因；一行也没有，说明 padmate 没收到这个键。见[诊断](09-diagnostics.zh-CN.md)。

## 手柄没有出现，或者输入重复

- 先确认手柄是 Xbox、PlayStation、Switch Pro 或 Joy-Con。Joy-Con 2 要按单独的步骤连接，见 [Joy-Con 2](15-joycon-2.zh-CN.md)。
- Steam、DS4Windows 和 HidHide 可能抢占手柄。诊断页的“冲突”指出正在运行的是哪一个并说明怎么办，见[诊断](09-diagnostics.zh-CN.md)。
- 手柄在“设置”页的“手柄调校”里写着“未识别为手柄”时，用[映射向导](11-mapping-wizard.zh-CN.md)建一份映射。

## 快捷键发不到某个软件

常见原因是管理员窗口、系统组合键、输入法吞掉裸字母键，以及个别软件漏掉组合键里的 Ctrl 或 Shift。

## 摇杆不推也在动，或者推不到头

在“设置”页的“手柄调校”里，点这只手柄的“调校”，推摇杆就能看到它的位置（一个圆点）。拉大“死区”，直到放手时圆点不再出圈；拉小“推到底”，摇杆不用推到头就算推到底。调校只对这只手柄生效。

## 有一个键卡住了

先用手柄上的紧急暂停：同时按住中间的两个小键 2 秒。还不行，用窗口里的“松开所有按键”，或运行 `padmatectl.exe release-all`。见[托盘和紧急释放](12-tray-and-emergency.zh-CN.md)。

## 启动时提示“设置已恢复”

设置文件有错误时，padmate 自动备份原文件，并把出错的部分恢复为默认值。对话框写着备份的名称，点“打开文件夹”可找到它，点“确定”关闭。备份不会自动清理，需要时自己删除。
