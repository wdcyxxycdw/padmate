# 脚本（宏）

[English](08-scripts.md)

脚本用代码决定一个键做什么。只在快捷键和序列不够用时才需要，例如等某个条件成立再按键。

脚本用 TypeScript 写。脚本库里的 `.padmate\padmate.d.ts` 列出脚本能用的函数，用 Visual Studio Code 编辑时有提示。

## 脚本页

左边点“脚本”，打开脚本页。脚本都放在 `%APPDATA%\padmate\macros` 文件夹里，所有配置共用这一个库。

- “新建”：输入名字，新建脚本并用编辑器打开。新脚本里有一个例子：全选，再复制。
- “导入”：把现成的 `.ts` 或 `.js` 文件放进脚本库。
- “重新加载”：脚本因反复出错停止后，让它重新开始。
- 每个脚本一张卡片，写着哪些键用了它，没人用则写“未使用”。卡片的菜单有“编辑”“重命名”和“删除”。脚本出错时，卡片上写着“出错”和原因，左边导航里的“脚本”上也会出现红点。

“编辑”用 Visual Studio Code 打开脚本，没有安装时用记事本，保存后很快自动生效。“重命名”同时改掉所有配置里的引用。“删除”会清空用到它的键，所以会先问你。

## 让一个键运行脚本

1. 打开键的设置，在映射里把“动作类型”选成“脚本”。
2. 在“选择脚本”里选一个。脚本库里还没有脚本时，这里写着“暂无脚本”，点“前往脚本页”去新建。
3. 之后每次这个映射发生，脚本就从头运行一次。脚本有错误时，键的设置里会写“此脚本有错误”。

## 一个例子

这个脚本按 Ctrl+A，等 50 毫秒，再按 Ctrl+C：

```ts
import { key, sleep } from "padmate";
export default async function () {
  await key.tap("Ctrl+A");
  await sleep(50);
  await key.tap("Ctrl+C");
}
```

## 规则

- 默认导出必须是函数，可以是 `async` 函数。
- 脚本只能用 padmate 提供的 `host`、`key`、`sleep`、`now`、`log`、`pad`、`session` 和 `padmate/math`，不能访问文件、网络和别的程序。
- 脚本还在运行时再按它的键不算，也不排队。
- 一次运行最长 60 秒，超过就被停止。结束时还按着的键会自动松开。要按着直到松开手柄键，请用快捷键。
- 暂停映射、紧急释放、锁屏、睡眠、切换配置和保存配置，都会打断运行中的脚本。
- 脚本死循环或栈溢出时会被停用，直到文件改动为止。10 分钟内第三次中断后永久停止，要在脚本页点“重新加载”。
