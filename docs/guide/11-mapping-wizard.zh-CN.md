# 映射向导

[English](11-mapping-wizard.md)

有些手柄的按键 padmate 读不懂：杂牌 USB 手柄，或调到 DirectInput 模式的手柄。映射向导按顺序请你按下或推动每个控件，把结果存成映射。之后这只手柄就是标准手柄，所有功能都能用。

## 什么时候用

- 手柄接上后，“设置”页的“手柄调校”里，它的名字旁边写着“未识别为手柄”。
- 手柄能用，但个别键位置不对，想重新对一遍。

## 建立映射

1. 左边点“设置”，在“手柄调校”里找到这只手柄，点“建立映射…”。
2. 向导弹出。向导期间 padmate 暂停所有手柄的映射，按键不会发给别的程序。
3. 先别碰手柄，稍等。向导在记摇杆放松时的位置。
4. 向导一步问一个控件，例如“按下 A 键”。按下或推动对应控件，向导写“检测到：按钮 3”并记下，再问下一个。
5. 问完所有控件后，向导列出记下的每一项，请你确认，点“保存”。
6. 没有要提醒的，窗口自己关闭。有提醒时，窗口写“映射已保存”，下面是提醒（见下一节），点“完成”关掉。

向导按这个顺序问：A、B、X、Y，十字键的上下左右，左摇杆的左、右、上、下和按下，右摇杆同样，LB、RB、LT、RT，最后是 View 和 Menu。padmate 不用 Home 键（Xbox 键、PS 键），所以向导不问它，见[层和功能键](03-layers-and-function-keys.zh-CN.md)。

这些按钮随时可用：

- “上一步”：回到上一个控件。
- “重做”：重记这一个控件。
- “跳过”：手柄没有这个控件时跳过，比如有的手柄没有右摇杆。
- “完成”：不再问剩下的控件，直接确认。
- “取消”：放弃，什么也不保存。

提示：

- 十字键一次只能按一个方向。扳机要压到底再松开，摇杆要推到头。
- 向导里的按钮、轴和十字键按 SDL 的序号数，从 0 开始，所以“按钮 3”是第四个按钮。

## 保存之后

映射按手柄型号生效，同型号的手柄共用一份。保存后窗口可能提醒：

- 没有映射 View 或 Menu。它们是默认紧急暂停的按键，没有它们，默认的紧急暂停就用不了，可在“手柄设置”里为这只手柄另设一个组合，见[托盘和紧急释放](12-tray-and-emergency.zh-CN.md)。
- 你设了环境变量 `SDL_GAMECONTROLLERCONFIG`，里面有这只手柄的映射。它优先于 padmate 的，所以刚保存的映射没生效。请改掉这个环境变量。

## 重新映射和恢复默认映射

- 手柄已被认出时，“手柄调校”里它那一行右边的菜单有“重新映射…”，向导同上。
- 做过自定义映射的手柄，名字旁边写着“自定义映射”，那个菜单有“恢复默认映射”，点它会先问“恢复默认映射？”。恢复后你做的映射被删除，手柄改回 SDL 自带的映射，SDL 没有则回到未识别的状态。
