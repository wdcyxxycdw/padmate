# CLIP STUDIO PAINT

[English](16-clip-studio-paint.md)

padmate 可以读 CLIP STUDIO PAINT（下称 CSP）自己的快捷键设置。给手柄的一个键选功能时，直接从 CSP 的命令和工具里选，不用先在 padmate 里录一个快捷键，再去 CSP 里把功能设到同一个键上。

这一章只对绑定了 CSP 的配置有用。绑定指配置里有一条软件规则，选中 `CLIPStudioPaint.exe`，见[配置和按软件切换](06-profiles.zh-CN.md)。随附的配置 CSP 已经绑定。没绑定的配置里看不到本章说的任何东西，设置里也没有对应的一栏。不读 CSP 时，映射照常工作。

## 为一个键选 CSP 的功能

1. 在“映射”页点一个键，打开按键抽屉。绑定的快捷键旁，“录入快捷键”按钮边上多了一个按钮“从 CLIP STUDIO PAINT 选择…”。
2. 在弹出的窗口里搜索名称、菜单路径或快捷键，或者按左边的分类找。选中一项，点“使用这个功能”。
3. 这个功能在 CSP 里的快捷键就填进了绑定里。抽屉里会写着它是 CSP 的哪个功能；这一步可以撤销，和别的编辑一样。

窗口里每个功能右边是它在 CSP 里现在的快捷键。没有快捷键的写着“未设置”。

## 选没有快捷键的功能

选中“未设置”的功能后，窗口会让你录一个键，再写进 CSP 的设置。

1. 录入一个键。padmate 马上说明这个键在 CSP 里属于谁：没人用，或者已经是哪个命令、哪个工具。padmate 不替你挑键，也不推荐空闲键。
2. 键可以写时，点“写入 CLIP STUDIO PAINT”。
3. 写完后窗口说明写进了什么。要退回，点“撤销这次写入”；不需要就点“完成”。

写 CSP 的设置之前，CSP 必须关着。CSP 在运行时，padmate 弹出“请先关闭 CLIP STUDIO PAINT”。关掉 CSP 后点“重试”；不想写了点“取消”。

每次写之前，padmate 先把 CSP 的两个快捷键文件备份。备份和恢复见本章最后的“设置”一节。

## 循环键和按住

- **循环键。**CSP 里几个工具可以共用同一个单键，每按一次换到下一个。padmate 看不到 CSP 现在选着哪个工具，所以按一次不一定切到你选的那个。窗口里这样的功能会标出循环键和共用它的工具。要按一次就切到它，给它一个独占的键，让 padmate 写进 CSP。
- **按住。**CSP 里的单键按住超过一段时间，会临时切换工具，松开后回到原来的工具。这段时间在 CSP 的首选项里设置。如果手柄的键是按住型的，发的又是这样的键，录键时 padmate 会提示。
- 修饰键设置占着的键，比如按住 Space 换工具，同样会提示，但不阻止。

## CSP 的快捷键变了

配置激活时，padmate 把这份配置记下的功能和 CSP 现在的设置比一次。配置激活期间 CSP 的文件变了，也会再比。

- 全部一致，什么都不做。CSP 里多出来的键不算差异。
- 有不一致，padmate 在 overlay 和托盘里提醒一句，不弹窗，也不把自己拉到前台，免得打断画画。
- 你打开 padmate 时，界面弹出“CLIP STUDIO PAINT 的设置变了”，一次列出全部差异，并给三个选择：
  - “以 padmate 为准”：把这些功能写回 CSP，让 CSP 回到配置记的样子。要先关掉 CSP，写之前会列出这样做会挤掉哪些功能的键。
  - “以 CLIP STUDIO PAINT 为准”：按键的功能不变，padmate 把映射里的键改成这个功能在 CSP 里现在的键。CSP 里已经没有快捷键的功能，保留原来的键，并标出来。
  - “暂不处理”：同样的差异不再提醒，差异再变了才提醒。

CSP 在运行时，它的工具设置是上次退出时的样子。所以运行中看到的工具差异可能是旧的，CSP 退出后会再比一次。

## 导出和导入

导出的配置文件带着它的 CSP 设置：每个键对应哪个命令或工具。

导入这样的配置后，如果和你的 CSP 有差异，padmate 弹出“导入的 CLIP STUDIO PAINT 设置”，列出差异，有三个选择：

- “用导入的设置改我的 CLIP STUDIO PAINT”：把导入的设置写进你的 CSP。只改与这份配置对应的几项，不覆盖你的整套快捷键。
- “不改，按我的 CLIP STUDIO PAINT 调整按键”：你的 CSP 不动，按键改成对应功能在你的 CSP 里现在的键。
- “以后再说”：什么都不改。

选第一项时，如果写入会让你的 CSP 里别的功能失去它的键，padmate 先列出这些功能，再让你点“逐项决定”。每一项有四个选择：

- “用导入的设置”：你原来的功能失去这个键。
- “保留本机的设置”：这一项不导入，用到这个键的按键会标出来。
- “给导入的功能换一个键”和“给本机的功能换一个键”：当场录一个新键，同样会查这个键在 CSP 里属于谁。

每一项都决定了才会写入。你的 CSP 里没有的命令，或别人自己做的辅助工具，会被跳过并列出来，对应的按键照旧发原来的键。

## 设置

“设置”页里，绑定了 CSP 的配置存在时，多出一栏 CLIP STUDIO PAINT。

- “数据位置”：padmate 找到的 CSP 设置文件夹。找不到、格式不认识或版本不支持时，这里写明原因。点“更换…”可以自己选这个文件夹，它要是里面有 `Shortcut` 或 `Tool` 的那个（名字像 `CLIPStudioPaintVer1_5_0`），不是的话 padmate 会告诉你。选过之后会出现“恢复自动查找”，点它就去掉你的选择。
- “备份”：每次写入前的备份，按时间列出，保留最近 30 份。点备份旁的“恢复…”，确认后 CSP 的快捷键设置换回那一份的样子。恢复同样要关着 CSP，恢复前会先备份现在的设置。

## 限制

- 只支持 CLIP STUDIO PAINT。
- 不保证 Microsoft Store 版和 Steam 版。
- 少数命令的名称可能只显示一个 ID：CSP 运行时生成的，和你自己做的命令，没有名称可读。
- 一些符号键对应哪个实体键还没有确认，窗口会写明，这样的键先不能判断是否被占用。
- CSP 升级后如果设置文件的结构变了，padmate 会关掉这项功能并提示，映射不受影响。
- CSP 的云备份可能把 padmate 写入的设置还原成旧的，padmate 管不到。
