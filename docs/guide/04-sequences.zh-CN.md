# 序列

[English](04-sequences.md)

序列让一个映射依次做几件事。

## 做一个序列

1. 在映射里把“动作类型”选成“快捷键”，录入第一个快捷键。
2. 点“增加动作序列”，选“快捷键”点按一个快捷键，或选“等待”停一会儿。
3. 这些步骤列在“按顺序发送”下面，叫“第 1 步”“第 2 步”……，用右边的按钮上移、下移或删除。

例如，全选再复制：

- 第 1 步，快捷键：Ctrl+A。
- 第 2 步，等待：50 毫秒。
- 第 3 步，快捷键：Ctrl+C。

说明：

- “等待”的时间从 1 到 10000 毫秒，新加的是 100 毫秒，从上一步松开起算。
- 序列最多 64 步，里面的快捷键都是点按。
- 序列没做完时再按这个键，新一次排在后面，最多排 16 次，多的丢掉。
- 暂停映射、切换配置和紧急释放会结束没做完的部分。
