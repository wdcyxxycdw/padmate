# 例 1：摇杆控速连发

运行方式见[脚本示例](../README.md)，配置是 `examples\scripts\stick-rate\profile.json`。

右摇杆向上发 F17，向下发 F18；向左、向右或回到死区则停止。死区为 20%，推到 95% 行程时达到 20 Hz，刚离开死区时约 3 Hz。

- 脚本每秒采样 125 次，反向时清掉累积的额度，停顿后不补发漏掉的点按。
- 每次点按按住 20 ms，同一个键的两次点按之间也至少隔 20 ms，所以物理上限是 25 Hz。本例只请求 3–20 Hz。

| 输出 | 建议在绘画软件里设置的快捷键 |
|---|---|
| F17 | 笔刷变大 |
| F18 | 笔刷变小 |
